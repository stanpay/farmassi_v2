# 채널별 템플릿 코드

새 채널에 등록한 뒤 이 표에 코드를 적는다.

## @팜어시

| kind | 템플릿명 | 코드 | 비고 |
|------|----------|------|------|
| order_done | 주문완료 안내 | `UO_1351` | 2026-11-23 등록 · 검수중 |
| tracking | 택배번호 안내 | `UO_1352` | 배송조회(DS) |
| delivered | 배송완료 안내 | `UO_1353` | |
| signup | 회원가입 완료 | `UO_1354` | 팜어시 전용 |

Senderkey: `.env` → `ALIGO_SENDER_KEY`
