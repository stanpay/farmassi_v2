# 확정 문구

변수는 알리고 형식 `#{이름}`. 발송 시 서버가 치환한다.

---

## 1. 주문완료 안내 (`order_done`)

- 채널: 팜어시 + 각 농가
- 버튼: 채널추가(AC)만 (채널추가 옵션으로 처리)
- 변수: `농가명`, `주문번호`, `상품명`, `배송지`, `배송예정일`, `결제금액`

```text
[#{농가명}] 주문완료 안내

□ 주문번호 : #{주문번호}
□ 상품 : #{상품명}
□ 배송지 : #{배송지}
□ 배송예정일 : #{배송예정일}
□ 결제금액 : #{결제금액}원

주문이 정상적으로 접수되었습니다.
배송 준비가 시작되면 다시 안내드릴게요.
```

`#{배송예정일}` 계산: `src/lib/deliveryEstimate.ts` / `server-py/app/shared/delivery_estimate.py`  
(`shipDate` → `arrivalDate` → `formatYmd`, 예: `11월 15일(토)`)

---

## 2. 택배번호 안내 (`tracking`)

- 채널: 팜어시 + 각 농가
- 버튼: **배송조회(DS)** + 채널추가
- 변수: `고객명`, `농가명`, `상품명`, `택배회사명`, `송장번호`

```text
#{고객명}님, #{농가명}에서 보내드린 상품이 발송되었습니다.

□ 상품 : #{상품명}
□ 택배사 : #{택배회사명}
□ 운송장번호 : #{송장번호}
```

---

## 3. 배송완료 안내 (`delivered`)

- 채널: 팜어시 + 각 농가
- 버튼: 채널추가만
- 변수: `고객명`, `농가명`, `상품명`

```text
#{고객명}님, #{농가명}에서 주문하신 #{상품명}이(가) 배송완료되었습니다.

맛있게 드세요.
```

---

## 4. 회원가입 완료 (`signup`)

- 채널: **@팜어시만** (농가 채널에 올리지 않음)
- 버튼: 채널추가만
- 변수: `고객명` (본문의 `팜어시`는 고정 문구)

```text
안녕하세요, #{고객명}님!

팜어시 회원가입을 환영합니다.
산지직송 농가 상품을 편하게 주문해 보세요.
```
