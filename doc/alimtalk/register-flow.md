# 채널별 템플릿 등록 절차

알리고 콘솔: https://smartsms.aligo.in/  
(로그인 계정은 `.env` 의 `ALIGO_USERID`)

문구·옵션 원본: [templates.md](templates.md) / [templates.json](templates.json)

## 0. 채널 준비 (농가)

1. 농가 카카오채널 개설 (사업자등록증 필요)
2. 알리고 → **카카오톡 → 카카오채널 관리 → 카카오채널 추가하기**
3. 상태가 **정상**이 되면 Senderkey 복사
4. 팜어시 관리자 → 농가 편집 → **알림톡 senderkey**에 붙여넣기 (`farms.aligo_sender_key`)

## 1. 템플릿 등록 (채널마다 반복)

경로: **카카오톡 → 템플릿관리 → + 템플릿 등록하기**

각 템플릿마다:

1. 강조유형 팝업 → **+ 기본형 템플릿**
2. 카카오채널 ID → 대상 채널 선택 (`@팜어시` 또는 농가 채널)
3. 템플릿명 → [templates.md](templates.md) 의 이름 그대로
4. 본문 → 해당 문구 복붙 (`#{변수}` 유지)
5. **채널추가** 체크
6. 택배번호만: 버튼타입 **배송조회(DS)** → **+ 버튼 추가**
7. **템플릿 등록 신청**

회원가입은 **@팜어시만**. 농가 채널에서는 1~3번(주문완료·택배번호·배송완료)만.

## 2. 대체문자 (문자 fallback)

등록 직후 `대체 문자 등록` 화면이 나오거나, 목록에서 템플릿 선택 → **대체문자 수정**.

1. **알림톡 전송 실패시 문자로 발송** 체크
2. 전송타입 **장문**
3. 본문 = 알림톡과 동일(변수 포함). 비어 있으면 알림톡 문구 붙여넣기
4. **대체 문자 저장하기**
5. 템플릿관리 목록 **대체문자** 열이 **`발송`** 인지 확인 (`발송안함`이면 미저장)

참고: 콘솔에 적은 대체문자는 **웹 발송**용. API 발송은 서버가 `failover` / `fmessage` 를 따로 보낸다 (`alimtalk.py`).

## 3. 검수

- 상태가 **검수중**이면 대기 (영업일 3~5일)
- **승인완료** 후 해당 채널로 실발송 가능
- 반려 시 사유 보고 수정 가능한 상태에서 고치거나, 승인본은 **복사 후 새 템플릿**으로 재등록

## 4. 코드 기록

발급된 `UO_xxxx` 를 [channels.md](channels.md) 에 적는다.

- 팜어시: `.env` 의 `ALIGO_TPL_*` 갱신
- 농가: 지금은 문구·구조가 같으면 **발송 시 senderkey만 교체**하는 전제.  
  알리고가 채널마다 **다른 템플릿 코드**를 주면 `farms` 에 템플릿 코드 컬럼을 추가해야 한다 (그때 스키마 확장).
