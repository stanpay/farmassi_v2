# 콜백문자 화면 흐름

실기기(갤럭시 S23 Ultra, `com.vnamu.automms` 2.023)에서 2026-11-08 에 확인했다. 기능과 판단 순서는 같고, 화면은 팜어시 디자인으로 만든다. 사진 첨부(MMS)·구독은 넣지 않는다.

하단 탭은 템플릿 / 발신 규칙 / 설정 세 개다. 팜어시는 농가 메뉴 **자동문자** 한 화면에 안내 문자(템플릿)와 규칙을 같이 둔다. 문구는 `farms.share_text` 하나다.

## 발신 규칙

위에 **자동 발신** 스위치가 있다.

- 켜짐: 규칙에 맞으면 바로 보낸다.
- 꺼짐(수동 모드): 통화가 끝나면 팝업이 떠서 보낼 문자를 고른다. 10초 뒤 닫히고, 고르지 않으면 보내지 않는다.

규칙이 없으면 "아직 규칙이 없어요". `+` 로 새 규칙을 만든다.

### 새 규칙

- 규칙 이름 (필수)
- 어떤 상황에: 발신 / 수신 / 부재중. 여러 개 고를 수 있다. 기본은 아무것도 안 고른 상태.
- 요일: **전체 요일** 스위치. 끄면 월~일 칩이 나온다. 월요일부터다.
- 시간대: **하루종일** 스위치. 끄면 시작 시각 ~ 종료 시각(기본 00:00 ~ 23:59).
- 재발송 제한
  - 제한 없음 (매번 발송)
  - 번호당 하루에 한 번
  - 번호당 일주일에 한 번
  - 번호당 평생 한 번
  - 직접 입력 (N일)
- 보낼 템플릿: 만들어 둔 템플릿 중 하나. 미리보기가 붙는다.

저장 시 겹치는 규칙은 상황·요일·시간대를 보여 준다. 목록에서 위에 있는 규칙이 먼저 적용된다.

## 문자 템플릿 (브이콜백)

템플릿에는 보낼 내용만 담는다. 언제 보낼지는 규칙이 정한다.

- 템플릿 제목 (필수)
- 문자 제목 (선택, MMS)
- 문자 내용 (필수). `{event}` `{number}` `{time}` 을 넣을 수 있다.
- 사진 첨부 (구독)

팜어시 1차는 안내 문자 1개만 쓰고 사진은 빼 둔다.

## 설정

- 구독 — 넣지 않는다.
- 주소록 관리: 이름·번호 추가, 주소록 동기화. 탭은 발송목록 / 미발송목록 / 전체목록. 팜어시는 **미발송(제외)** 만 둔다. 앱에서 주소록 목록을 불러 여러 명을 고르거나, 주소록 전체를 한 번에 제외할 수 있다. 지역번호와 070은 자동 제외.
- 전송 이력: 전송/미전송, 시각, 상황(통화 종료·부재중), 번호, 자동 판정, 미전송 사유. 비우기 버튼.
- 문자 테스트: 번호 확인 후 전송.

## 권한 (실기기)

`READ_PHONE_STATE`, `READ_CALL_LOG`, `SEND_SMS`, `SYSTEM_ALERT_WINDOW`, `RECEIVE_BOOT_COMPLETED`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`. MMS용 `RECEIVE_SMS` / `RECEIVE_MMS` 는 쓰지 않는다.

리시버는 `PHONE_STATE` 와 `BOOT_COMPLETED`. 앱을 강제 종료하면 감지가 멈춘다.
